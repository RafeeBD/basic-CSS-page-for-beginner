# Basic CSS Practice for Beginners 🚀

A beginner-friendly collection of fundamental CSS concepts, layout techniques, positioning examples, and practice demonstrations.

---

##  Topics Covered

- **Basic Selectors & Styling**: Class selectors, ID selectors, typography, and color styling.
- **CSS Positioning**: Demonstration of `static`, `relative`, `absolute`, `fixed`, and `sticky` positioning.
- **CSS Overflow**: Examples of `visible`, `hidden`, `scroll`, `auto`, and `clip` overflow behaviors.
- **Flexbox**: Layout positioning, direction (`column-reverse`), and wrapping (`wrap-reverse`).
- **CSS Grid**: 2D layout design, multi-column tracks (`repeat(4, 1fr)`), item column spanning (`grid-column: span`), and item targeting (`:first-child`, `:nth-child`, `:last-child`).
